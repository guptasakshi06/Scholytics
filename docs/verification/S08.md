## Implemented behavior

- [App](../../app/streamlit_app.py) is a thin adapter over [session/upload/export helpers](../../src/scholarready/ui.py) and shared `pipeline.analyze`. The pipeline adds optional page-progress notifications; readiness/classification/extraction rules are unchanged. One decoder diagnostic now omits PIL's nondeterministic BytesIO memory address, preserving a stable explicit corrupt-input error across CLI and UI.
- Multi-file PNG/JPEG/PDF; explicit fictional profile; category true/false/unknown; expected name and application reference labelled as user input; optional unverified type hints; A/B/C selection and locally trusted S05 model choice. Learned/settings mismatch and missing/corrupt local artifacts give actionable errors. No arbitrary pickle/model upload or manual field correction is offered.
- All requirements/reasons/actions, global issues, separate original quality, classification decisions/scores, raw/normalized fields/roles/units/candidates, document/page selectors, original/processed images, OCR/evidence boxes and optional stage/geometry/provenance views.
- Shared-schema JSON and findings CSV. CSV contains every requirement plus global issues and guards formula-like values. Image paths refer to the disposable run; there is no image archive or PDF-report export.
- Session-owned `TemporaryDirectory`, no global applicant cache. Indexed input directories preserve repeated filenames. Uploaded byte copies are removed after inference; pages/stages are removed when invalidated or cleared. Session expiration/garbage collection handles disconnected sessions; abrupt termination is not a secure-erasure guarantee. Bounds/OCR defaults are unchanged.
- Request identity includes ordered file bytes/names/hints, full applicant/config/preprocessing, classifier metadata/method, shared limits/OCR settings and package source hashes. Profile/file/hint/model/branch changes invalidate results. Reset assigns explicit widget defaults and advances the file-widget generation; it does not rely on deleting profile keys.
